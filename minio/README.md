# HyperVaults MinIO

MinIO stores uploaded file bytes for local development.

## Bucket

The bucket name is:

```text
hypervaults-files
```

`minio-init/create-bucket.sh` creates the bucket if needed and sets anonymous access to `none`. The bucket is private by default.

## Object Keys

The backend stores files under per-user paths:

```text
users/{user_id}/{uuid}-{sanitized_filename}
```

The object key is never trusted from the client. It is generated by the backend after authentication.

## Console

The MinIO console is available at:

```text
http://localhost:9001
```

Use the local development credentials from `.env`. Do not use those values outside local development.
